LoRA(LoRA: Low-Rank Adaptation) 학습 파라미터를 설정할 때 고려해야 할 요소와 설정 근거를 설명하겠습니다.  

---

 1. 기본 개념  
LoRA는 기존 모델의 전체 가중치를 업데이트하는 대신, 특정 가중치 행렬에 대해 저차원(low-rank) 근사 행렬을 학습하여 파라미터 효율성을 높이는 기법입니다. 이를 통해 메모리 사용량을 줄이고 학습 속도를 개선하면서도 성능을 유지할 수 있습니다.  

---

 2. 주요 파라미터와 설정 근거  

 (1) Rank (R)
- 설정 근거: R 값이 클수록 모델이 더 많은 자유도를 갖지만, 파라미터 수가 증가하여 메모리 사용량과 계산 비용이 증가함.  
- 일반적인 설정:  
  - 작은 모델 (7B 이하): `R=4~16`  
  - 중간 크기 모델 (13B~30B): `R=8~32`  
  - 대형 모델 (65B 이상): `R=16~64`  
- 우리의 경우:  
  - LLaMA3 Blossom을 대상으로 소방·화재 사고 데이터 학습 → Rank를 8~16 범위에서 설정하는 것이 적절함.  
  - 메모리 고려 → A100 사용 예정이므로, R=16까지는 충분히 감당 가능.  
  - 도메인 특화 학습 → Rank가 너무 낮으면 충분한 표현력을 확보하기 어려움.  

 (2) Alpha (LoRA Scaling)
- 설정 근거: `α`는 LoRA 가중치 행렬의 스케일을 조정하는 하이퍼파라미터로, 모델의 업데이트 크기에 영향을 미침.  
- 일반적인 설정: `α = 2R`  
  - R=8 → α=16  
  - R=16 → α=32  
- 우리의 경우:  
  - R=8 → α=16, R=16 → α=32로 설정하면 학습 안정성을 확보할 수 있음.  
  - Rank가 낮을 경우 α 값을 약간 더 높여도 무방함(R=8일 때 α=24).  

 (3) Dropout
- 설정 근거: LoRA 가중치가 과적합되는 것을 방지하기 위해 사용.  
- 일반적인 설정: `0.05 ~ 0.1`  
- 우리의 경우:  
  - 도메인 특화 데이터(사고 사례) 학습 → 상대적으로 데이터셋이 작고 특정 패턴을 학습해야 하므로 Dropout=0.05 수준이 적절함.  
  - 데이터가 많으면 Dropout을 0.1까지 올려도 무방함.  

 (4) 적용 대상 Layer
- 설정 근거: 모든 가중치 행렬에 LoRA를 적용하는 것은 비효율적이므로, 특정 레이어(W_q, W_v 등)에만 적용하는 것이 일반적.  
- 일반적인 설정:  
  - Transformer 모델에서는 주로 `query (W_q), value (W_v)` 행렬에 적용.  
  - 일부 경우 `W_k, W_o`에도 적용 가능하지만, 보통 `W_q, W_v`만으로 충분한 성능 확보 가능.  
- 우리의 경우:  
  - LLaMA3 Blossom 모델 사용 → `W_q, W_v`에만 LoRA 적용 (기본 설정 유지).  
  - 추가 실험을 통해 `W_o`에도 적용할지 검토 가능.  

 (5) Learning Rate (LR)
- 설정 근거: LoRA는 기존 모델의 가중치를 거의 유지하면서 새로운 가중치만 학습하므로 일반적인 fine-tuning보다 낮은 학습률을 사용.  
- 일반적인 설정: `1e-4 ~ 5e-4`  
- 우리의 경우:  
  - Fire incident data에 대한 도메인 적응이 목표이므로 1e-4 수준에서 시작.  
  - 데이터 양이 많거나 더 빠른 수렴을 원하면 2e-4까지 올릴 수 있음.  

 (6) Batch Size
- 설정 근거: LoRA는 파라미터 수가 적으므로 비교적 큰 배치 사이즈를 사용할 수 있음.  
- 일반적인 설정:  
  - VRAM 24GB (A100 40GB 이하) → `8~32`  
  - VRAM 80GB 이상 → `32~64`  
- 우리의 경우:  
  - A100 GPU 사용 예정이므로 Batch Size 16~32가 적절.  
  - GPU 메모리 사용량에 따라 조절 가능.  

 (7) Optimizer
- 설정 근거:  
  - LoRA는 적은 가중치만 업데이트하므로 Adam 계열 옵티마이저를 주로 사용.  
- 일반적인 설정:  
  - `AdamW` + `weight decay 0.01`  
- 우리의 경우:  
  - AdamW(β1=0.9, β2=0.999) 사용, `weight_decay=0.01` 설정 유지.  

---

 3. 최종 추천 설정  

| Parameter | Value |
|-----------|-------|
| Rank (R) | 8~16 |
| Alpha (α) | 16~32 (`α = 2R`) |
| Dropout | 0.05 |
| Target Layers | `W_q, W_v` |
| Learning Rate | 1e-4 ~ 2e-4 |
| Batch Size | 16~32 |
| Optimizer | AdamW (weight_decay=0.01) |

---

 4. 결론
- Rank=8~16, Alpha=2R 설정으로 도메인 특화 모델 학습 안정성을 확보.  
- Dropout=0.05로 설정해 특정 패턴 학습을 유지하면서도 과적합 방지.  
- W_q, W_v에만 적용하여 최소한의 계산량으로 효과적인 성능 향상.  
- Learning Rate=1e-4~2e-4로 설정해 적절한 수렴 속도를 보장.  
- A100 사용 시 Batch Size 16~32가 적절.  

이 설정을 기반으로 실험을 진행한 후, 추가적인 조정이 필요하면 변경하면 됩니다.
